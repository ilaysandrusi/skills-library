# Scripts (משותפים)

Executable helpers a project keeps at its repo root and shares across its skills. The skills shell out to these; they are not skills themselves.

**קבצים כאן:** 264 — מ-3 מקורות.

כל מה שכאן הוא **scripts ברמת הריפו**: במעלה הזרם הוא יושב בשורש הפרויקט ומשרת את כל הסקילים שלו במקביל, ולכן אי אפשר לשייך אותו לסקיל אחד ואין להכפיל אותו לכל סקיל. הסקילים מפנים לכאן בנתיב יחסי.

בכל תיקיית מקור יש `SOURCE.md` עם הריפו במעלה הזרם, הנתיב, ה-commit והרישיון.

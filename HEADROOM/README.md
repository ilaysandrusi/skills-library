# HEADROOM

סקילים וכלים שנותנים לסוכנים יותר זיכרון, הקשר ורציפות עבודה בין סשנים.

**מספר סקילים:** 2

| סקיל | מה הוא עושה |
|---|---|
| [`claude-mem`](./claude-mem/SKILL.md) | כלי זיכרון לסוכני קוד כמו Claude Code, Codex, Cursor, OpenCode ו-Gemini. משתמשים בו כשרוצים שהסוכן יזכור סשנים קודמים, יחפש החלטות ותיקונים מהעבר, יכניס הקשר רלוונטי לעבודה חדשה, וימשיך פרויקט בלי להסביר הכול מחדש. |
| [`task-observer`](./task-observer/SKILL.md) | סקיל שמשקיף על העבודה עם סוכני AI וסקילים אחרים. הוא מזהה דפוסי עבודה שחוזרים על עצמם, תיקונים שהמשתמש נותן, פערים בסקילים קיימים ורעיונות לסקילים חדשים, ושומר אותם כתצפיות מסודרות כדי לשפר את ספריית הסקילים לאורך זמן. |

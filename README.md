## איך ללמוד

1. פתח קטגוריה למטה.
2. קרא את טבלת השמות ב-README של הקטגוריה.
3. היכנס לתיקיית הסקיל ופתח את `SKILL.md`.

לחיפוש סקיל לפי שם או נושא: `catalog.json` מכיל את האינדקס המלא, או חפש עם `rg -i "מילת-מפתח" catalog.json`.

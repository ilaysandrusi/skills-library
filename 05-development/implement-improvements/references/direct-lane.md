## Phase 1: Run `/turbo-implement` Skill

In the turn that invokes `/turbo-implement`, write out each fix in the working set as an explicit bullet: summary + files + change description. If an entry turns out to need broader scope or deeper analysis during implementation, stop and re-classify it as `investigate` or `plan` (leave it in the backlog for a future run).

Then run the `/turbo-implement` skill.

Then use the TaskList tool and proceed to any remaining task.

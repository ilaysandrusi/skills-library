# Tasks (משותפים)

Step files a plugin shares across the skills of that plugin.

**קבצים כאן:** 7 — מ-1 מקורות.

כל מה שכאן הוא **tasks ברמת הפרויקט**: במעלה הזרם זה יושב בשורש הריפו (או ברמת הפלאגין) ומשרת את כל הסקילים שלו במקביל, ולכן אי אפשר לשייך את זה לסקיל אחד ואין להכפיל את זה לכל סקיל. הסקילים מפנים לכאן בנתיב יחסי.

בכל תיקיית מקור יש `SOURCE.md` עם הריפו במעלה הזרם, הנתיב, ה-commit והרישיון.
